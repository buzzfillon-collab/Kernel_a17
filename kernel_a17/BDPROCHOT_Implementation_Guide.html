📋 Project Overview

What This Does

Disables BDPROCHOT (Broadwell DRAM Power-OK) throttling on Intel x86 laptops, which prevents severe CPU performance degradation when using non-genuine chargers or batteries.

  • Without patch: 10-50% CPU throttling with third-party chargers
  • With patch enabled: Full turbo boost performance maintained
  • Default setting: Disabled (safe, user must opt-in)
  • How it works: Clears bit 38 of MSR 0x1A0 at early CPU boot

💡 What This Does

Defines the BDPROCHOT bit (bit 38) of the IA32_MISC_ENABLE MSR register. This is a preprocessor macro that creates a bitmask for manipulating the BDPROCHOT throttling control flag. When this bit is set, BDPROCHOT throttling is enabled. When cleared, throttling is disabled.

CODE TO ADD - COPY ENTIRE BLOCK 
/* Disable BDPROCHOT throttling if configured */
static void intel_disable_bdprochot(void)
{
#ifdef CONFIG_DISABLE_BDPROCHOT
	u64 misc_enable;
	
	if (rdmsrl_safe(MSR_IA32_MISC_ENABLE, &misc_enable))
		return;
	
	if (misc_enable & MSR_IA32_MISC_ENABLE_BDPROCHOT) {
		misc_enable &= ~MSR_IA32_MISC_ENABLE_BDPROCHOT;
		wrmsrl_safe(MSR_IA32_MISC_ENABLE, misc_enable);
		pr_info("x86/intel: BDPROCHOT throttling disabled\n");
	}
#endif
}
💡 What This Does
  • Reads MSR safely: Gets the current value of IA32_MISC_ENABLE
  • Checks BDPROCHOT: Tests if bit 38 is set (throttling enabled)
  • Clears the bit: Uses bitwise AND with inverted mask to disable throttling
  • Writes back: Updates the MSR register with new value
  • Logs status: Prints message to kernel log for verification
  • Conditional: Only compiled if CONFIG_DISABLE_BDPROCHOT=y
📝 Code Explanation
#ifdef CONFIG_DISABLE_BDPROCHOT - Only compile this code if the config option is enabled
u64 misc_enable; - 64-bit variable to hold MSR value
rdmsrl_safe() - Safely read MSR (returns 0 on success)
& (AND) - Check if BDPROCHOT bit is set
&= (AND with NOT) - Clear the BDPROCHOT bit
wrmsrl_safe() - Safely write MSR back
pr_info() - Print to kernel log (see with dmesg)

🔨 Build Instructions

Step 1: Generate Default Config

cd kernel-root/
make android15-6.6_defconfig
# or: make gki_defconfig (depending on your device)

Step 2: Enable BDPROCHOT Disabling (Optional)

# Interactive method:
make menuconfig
# Navigate to: Processor type and features
#            → Disable BDPROCHOT throttling
# Mark with [*] to enable, then save

# OR direct method:
echo "CONFIG_DISABLE_BDPROCHOT=y" >> .config

Step 3: Build the Kernel

# Using all CPU cores (recommended)
make -j$(nproc)

# Or specify number of cores
make -j8  # Replace 8 with your number of cores

Step 4: Create Boot Image

# Build modules
make modules

# Install modules to staging directory
mkdir -p staging
make INSTALL_MOD_PATH=staging modules_install

# Next: Use device-specific mkbootimg to create boot image
# (This varies by device - check AOSP documentation)

Step 5: Flash and Verify

# After booting the kernel:

# Check if BDPROCHOT was disabled (if CONFIG enabled)
adb shell dmesg | grep -i bdprochot
# Expected: "x86/intel: BDPROCHOT throttling disabled"

# Check MSR value (requires msr-tools package)
adb shell rdmsr 0x1a0 | od -t x8

# Monitor CPU frequency (should stay high, not throttle)
adb shell watch -n 0.1 "cat /proc/cpuinfo | grep MHz"
⚠️ Device-Specific Steps
The boot image creation and flashing process is specific to your device. Consult your device's AOSP documentation or manufacturer guidelines for:
  • Correct mkbootimg parameters
  • Bootloader unlock procedure
  • Flashing method (fastboot, custom recovery, etc.)
  • Recovery image requirements
